# Offline certificate explorer

Extract the two files together and open index.html. The rotating schematic shows the origin, first two basis vertices, and one short auxiliary vertex. The actual proof uses a sufficiently high dimension; the pictured 3D simplex is a projection for orientation.

The boundary selector substitutes a rational normalized boundary into the stopping comparison on the repeated e₁ history. It displays the numerical result of the inequality, independently of the actual round at which the boundary reaches that size. The algorithm returns an action of margin 1/2 on this history, while the required true margin is 9/16.
